# 📱 워터마크 지우개 (CleanMark) - 안드로이드 온디바이스 앱

PC나 외부 서버 연결 없이, **스마트폰 단독으로 갤러리의 사진과 동영상 워터마크를 100% 로컬에서 지우는 안드로이드 전용 앱**입니다.

---

## 📦 APK 설치 파일 위치

프로젝트 루트 폴더에 스마트폰에 바로 설치할 수 있는 APK 파일이 준비되어 있습니다:
```
d:\Projects\Android\RmWaterMark\워터마크지우개.apk
```
(또는 `d:\Projects\Android\RmWaterMark\build\app\outputs\flutter-apk\app-debug.apk`)

---

## 📲 스마트폰에 설치하는 방법 (3가지 중 택 1)

1. **카카오톡 '나와의 채팅' 전송 (가장 추천 ⭐)**:
   * PC 카카오톡을 켜고 `워터마크지우개.apk` 파일을 '나와의 채팅' 방에 전송합니다.
   * 스마트폰 카카오톡에서 해당 파일을 터치하여 **[설치]**를 누르면 바로 깔립니다.
2. **USB 케이블 연결**:
   * 스마트폰을 PC에 USB로 연결하고, `워터마크지우개.apk` 파일을 스마트폰의 `Download` 폴더에 복사합니다.
   * 스마트폰의 '내 파일(파일 관리자)' 앱에서 터치하여 설치합니다.
3. **구글 드라이브 / 클라우드**:
   * 구글 드라이브나 SendAnywhere 등에 올려 스마트폰에서 다운로드 후 설치합니다.

> 💡 **설치 팁**: 플레이스토어 외부 파일이므로 스마트폰에서 *"출처를 알 수 없는 앱 설치"* 안내가 나오면 **[허용]** 또는 **[무시하고 설치]**를 눌러주시면 됩니다.

## ✨ 핵심 기능 및 스마트폰 최적화 UX

1. **🔒 100% 온디바이스 (외부 서버 업로드/다운로드 없음)**:
   * PC를 완전히 끄고 비행기 모드나 야외 이동 중에도 스마트폰 혼자서 동작합니다.
   * 개인 사진이나 동영상이 인터넷으로 유출될 걱정이 전혀 없습니다.
2. **📸 갤러리 원터치 선택**:
   * 앱 실행 후 사진/동영상 카드를 누르면 스마트폰 사진첩이 즉시 열립니다.
3. **⚡ 1초 원터치 프리셋 버튼 (가장 편리한 모바일 기능)**:
   * 틱톡, 인스타 릴스, 유튜브 쇼츠, 로고 등 자주 위치하는 영역을 터치 한 번으로 지정합니다.
   * **[📍 우측 하단]** / **[📍 좌측 하단]** / **[📍 상단 자막]** / **[📍 중앙 로고]**
4. **손가락 드래그 & 제스처**:
   * 화면 위에서 손가락으로 드래그하여 원하는 크기로 사각형 박스를 자유롭게 지정할 수 있습니다.
5. **🎬 동영상 워터마크 삭제**:
   * 동영상 속 워터마크 위치를 지정하면, 폰 안에서 프레임별로 깨끗하게 삭제하고 새로운 MP4 동영상으로 렌더링합니다. (오디오 무손실 보존)
6. **터치 앤 홀드 비포/애프터 비교**:
   * 화면을 **손가락으로 꾹 누르고 있으면 [원본]**, **손을 떼면 [제거본]**이 즉시 토글되어 비교할 수 있습니다.
7. **💾 갤러리에 원클릭 저장 & 카카오톡 바로 공유**:
   * [스마트폰 갤러리에 저장] 버튼을 누르면 사진첩에 즉시 저장됩니다.
